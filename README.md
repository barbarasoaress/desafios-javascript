# 💻 Desafios JavaScript

Repositório criado para registrar minha evolução em JavaScript através de desafios progressivos de lógica de programação.

O objetivo é aprender não apenas a sintaxe da linguagem, mas principalmente desenvolver raciocínio lógico, resolução de problemas e prática com Git e GitHub.

---

## 🎯 Objetivos

- Praticar JavaScript constantemente
- Desenvolver lógica de programação
- Resolver problemas sem copiar soluções prontas
- Revisar conteúdos já estudados
- Aprender Git e GitHub na prática
- Construir um histórico de evolução no GitHub
- Avançar dos fundamentos até projetos mais completos

---

## 🧠 Método de estudo

Para cada desafio:

1. Ler e entender o problema
2. Tentar criar a solução sozinha
3. Pedir apenas pistas quando necessário
4. Testar o código no terminal
5. Corrigir e melhorar a solução
6. Fazer `git add`
7. Criar um `git commit`
8. Enviar para o GitHub com `git push`
